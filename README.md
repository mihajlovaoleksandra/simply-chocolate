Simply Chocolate

Project description

HTML markup practice project for the GoIT course.

Lesson plan

Prepare the project structure.

Create the HTML document.

Add images from the Figma layout.

Write semantic HTML markup.

Format the code with Prettier.

Validate the HTML code.

Commit and push changes to GitHub.

Technical requirements

The HTML file is named index.html.

The images folder is located in the project root.

File names contain only English letters and numbers, without spaces.

The code is formatted with Prettier.

All images and text are taken from the Figma layout.
